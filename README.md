# IRONPULSE Website V2

A polished, responsive static shop for a single gym cable attachment.

## Included
- Premium dark fitness-store design
- Product/hero pages with original CSS product artwork
- Basket quantity controls
- Starter checkout/order-email flow
- Shipping & returns page
- Privacy page
- Terms page
- Mobile responsive layout
- No external libraries required

## Important before launch
1. Replace `orders@example.com` in `script.js`.
2. Replace placeholder business details on the legal pages.
3. Add your own original product photographs in place of the CSS artwork if you have them.
4. Confirm the exact product dimensions/materials and only publish specifications that match your stock.
5. Add a real payment provider (for example Stripe or PayPal) before accepting card payments.
6. Add your real delivery charges, dispatch times and returns procedure.
7. Check UK consumer, tax and business requirements for your circumstances.

## Pricing
The first version uses £24.99 as a test selling price. Current UK market listings for similar tricep ropes vary considerably, so test your conversion rate, postage and all selling costs before settling on a long-term price.

## Product imagery
The site currently uses original CSS artwork so the package is self-contained. If you have the physical stock, taking your own photos is preferable to copying another seller's images. Good shots to add:
- clean front/angled product shot
- close-up of grip/end caps
- attachment point
- product in use on a cable machine
- packaging / what is included

## Free hosting
This is a static website and can be hosted on a free static-hosting service such as GitHub Pages or Cloudflare Pages. Connect your own domain later if you want a branded address.

## No fake reviews
The site intentionally contains no fabricated customer reviews. Add genuine reviews only after real customers have used the product.

## Monzo payment
The primary Buy Now buttons now point to the reusable Monzo payment link supplied for IRONPULSE at £24.99. The site does not expose the seller's bank account/IBAN details.

## Generated imagery
AI-generated marketing imagery has been added as a visual starting point. It should be replaced with original photographs of the exact stock before launch if the generated product differs from the real item.
